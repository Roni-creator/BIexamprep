00:00:00:00 Intro to Multimedia Q1 ▶

Multimedia is the integration of multiple media elements — text, audio, images, video, and animation — delivered through computer systems using hardware and software to create, store, and present information.

Minoli & Keinath: multimedia is an interdisciplinary, application-oriented technology that leverages the multi-sensory nature of humans.

  • Interdisciplinary — combines graphic design, computer science, audio/video production
  • Application-oriented — applied in real-world contexts
  • Multi-sensory — sight→images, hearing→audio, touch→haptics, smell/taste→emotion & memory (indirect)

Goals

  • Improve communication efficiency · Enhance understanding · Interactive learning · Engage multiple senses · User-friendly delivery

Historical Evolution

EraDevelopments
Pre-1980sText-based computing, limited graphics
1980s–1990sGUI introduced, CD-ROM
1990s–2000sInternet & WWW, widespread multimedia apps
2000s–NowStreaming, mobile, social media, cloud multimedia

Uses

  • Education — simulations, e-learning
  • Business/Marketing — presentations, advertising
  • Entertainment — gaming, film, music
  • Social Media — posts, video calls
  • Healthcare — medical imaging, telemedicine
  • Knowledge Systems — digital libraries

Multimedia Application

A designed platform/toolset supporting interactive use of multimedia elements, enabling storage, compression, retrieval and delivery to meet a user or business objective. Key traits: integration, interactivity, digital representation, usability.

00:14:08:07 Sound & Audio Q4 ▶

Sound is a mechanical, longitudinal wave produced by vibrations that propagate through a medium as compressions and rarefactions.

Wave Characteristics

  • Pitch/Frequency — higher frequency = higher pitch
  • Amplitude/Loudness — magnitude of disturbance
  • Timbre — differentiates same-frequency sounds
  • Wavelength — distance between wave peaks

Sound vs Audio: Sound = physical wave. Audio = digital representation of sound.

Digitization Process

  • 1. Sampling — measuring analog signal at intervals (Hz). Nyquist: fs ≥ 2×fmax. Below that → aliasing.
  • 2. Anti-aliasing — low-pass filter before sampling
  • 3. Quantization — rounding amplitudes to discrete levels. Bit depth 8/16/24/32 — more bits = finer resolution. Dithering adds noise before rounding to reduce distortion.
R = fs × b × C
File Size = (fs × b × C × T) / 8

CD-quality stereo example: 44.1kHz × 16 × 2 = 1.411 Mbit/s

Compression & Streaming

  • Perceptual coding uses frequency/temporal masking + critical bands; guides bit allocation (MP3/AAC)
  • Streaming types: full download, progressive, on-demand, live, real-time
  • HLS (Apple, adaptive) · MPEG-DASH (international standard) · WebRTC (low-latency, Opus)
  • Artefacts: muffling, pre-echo, warbling, metallic sound, stereo collapse, noise pumping

00:33:10:20 Multimedia Compression Q3 ▶

Reducing the data required to store, transmit, or process multimedia content while maintaining acceptable quality.

Redundancy Types

TypeDescription
Statistical/CodingFrequent values get shorter codes
TemporalConsecutive frames similar — store differences
SpatialNeighbouring pixels similar — store once
Perceptual/PsychovisualRemove details the eye won't notice
SpectralCorrelated channels/frequencies — remove overlap
StructuralRepeating patterns — store once, reference later
PsychoacousticRemove sounds the ear won't hear

Lossless vs Lossy

  • Lossless — no data removed (RLE, Huffman, Dictionary coding); exact reconstruction
  • Lossy — permanent removal (Quantization, Transform coding, Perceptual coding); approximate reconstruction

Image Compression

  • JPEG — DCT on 8×8 blocks, converts pixels → frequency components; lossy; eye tolerates colour loss more than brightness loss
  • PNG — lossless (DEFLATE), supports transparency
  • AVIF — AV1-based, better compression
  • Generation loss — quality drops each time a lossy image is re-saved
  • Example ratio: 25MB → 4MB JPEG = 6.25:1

Audio Compression

  • Psychoacoustic modelling drives lossy audio compression
  • FLAC uses prediction + residual + entropy coding (lossless)
  • Lossless preferred in music production — avoids generation loss
  • Bit allocation distributes bits by perceptual importance

Video Compression

  • I-frame — complete, independent image
  • P-frame — predicts from previous I/P, stores differences
  • B-frame — predicts from past + future frames, most efficient
  • Motion estimation — finds matching blocks in reference frames; a motion vector describes displacement
  • Uncompressed example: 1280×720, 30fps, 24-bit ≈ 79.1 MB/s ≈ 4.75 GB/min
  • Container (MP4, MKV) wraps video/audio/subtitles · Codec (H.264, H.265) encodes/decodes the data

00:47:18:00 Multimedia Development Life Cycle Q5 ▶

A structured sequence of steps guiding a project from idea to delivered product. Without it: disorganization, quality loss, missed deadlines, wasted resources.

PLANNING → DESIGN → MATERIAL COLLECTION → DEVELOPMENT → TESTING → DEPLOYMENT → FOLLOW-UP (Management runs across all phases)

  • 1. Planning — define the idea, kick-off meeting, project scope, understand audience, define core message, market research
  • 2. Design — structure/navigation/content plan; goals: simplicity, consistency, user involvement, affordability; brainstorm → storyboard; information design; prototyping (catch problems early)
  • 3. Material Collection — gather/create raw media; sources: borrow (open-source), lease, purchase, make your own; legal clearance is critical
  • 4. Development — longest, most resource-intensive; integrate materials, program, connect databases, use authoring tools
  • 5. Testing — functionality, usability, compatibility, accessibility; catch bugs, validate UX, protect reputation
  • 6. Deployment — publish/distribute; timing, scalability, backup & recovery, staged rollout
  • 7. Follow-Up — keep meeting objectives post-launch; gather feedback, fix issues, improve continuously

Management (runs across all phases): planning, estimating, monitoring, controlling — people, technologies, resources, environment.

00:55:40:08 Sample CAT Questions All ▶
Q1 · 5 MARKSMinoli & Keinath

Interpret the definition and explain "multi-sensory nature" in the context of multimedia.

Answer

Interdisciplinary (combines fields) · Application-oriented (real-world use) · Multi-sensory (sight→images, hearing→audio, touch→haptics, smell/taste→emotion & memory, indirectly).

Q2 · 6 MARKSText design principles

Discuss THREE text design principles.

Answer

Any three of: Readability, Legibility, Contrast, Consistency, Spacing, Hierarchy.

Q3 · 2 MARKSText alone insufficient

"Text used alone as a media type is not sufficient." Explain the accuracy of this statement.

Answer

Combining media improves engagement, understanding, and interactivity. Retention rises when multiple senses are engaged (e.g. ~50% for see+hear, ~80% for see+hear+do). Text alone struggles to convey complex visual/spatial information.

Q4 · 2 MARKS24-bit vs 32-bit

State the major difference between 24-bit and 32-bit image depth.

Answer

24-bit = RGB, 8 bits/channel → 16.7M colours. 32-bit adds an Alpha channel for transparency/opacity control.

Q5 · 2 MARKSGIMP — watermark

Which layer property softens a watermark blocking an image in GIMP?

Answer

Opacity — reducing it makes the watermark layer partly transparent, letting the image show through.

Q6 · 3 MARKSGIMP — gradient hides tree

A gradient is applied and the tree becomes invisible — what went wrong and how is it fixed?

Answer

The gradient was applied on the same layer as the tree. Fix: separate layers for tree and gradient, apply the gradient on its own layer, keep the tree layer in front, and select the correct layer before editing.

Formulas

Audio Bitrate: R = fs × b × C

Video Size: width × height × bit depth × frame rate × duration
Compression Ratio: Original Size ÷ Compressed Size
Nyquist: fs ≥ 2 × fmax

Key Differences

  • Lossless vs Lossy — no removal/exact/larger files vs. removal/approximate/smaller files
  • Raster vs Vector — pixels, degrades on scale (photos) vs. equations, scales perfectly (logos)
  • 2D vs 3D Animation — faster/less realistic vs. slower/more realistic, unlimited viewpoints
  • Mono vs Stereo vs Spatial — 1 channel vs. 2 (L/R) vs. multi-channel 3D immersion
  • Container vs Codec — wrapper (MP4, MKV) vs. encoding algorithm (H.264, H.265)
